# 🍅 Pomodoro Timer

> Pomodoro Timer moderno desenvolvido com React, TypeScript e Vite. Focado em arquitetura limpa, separação de responsabilidades com Custom Hooks e alta confiabilidade através de testes automatizados unitários e de integração com Vitest e Testing Library.

---

## 🛠️ Tecnologias

- **React** & **TypeScript**
- **Tailwind CSS**
- **Vite**
- **Vitest** & **React Testing Library**
- **ESLint**

---

## 🚀 Como executar

```bash
# Instalar dependências
npm install

# Iniciar o servidor de desenvolvimento
npm run dev

# Executar os testes automatizados
npm test

# Executar a verificação de lint
npm run lint
```
